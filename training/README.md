# Elvin — навчання AI-технолога (v0.1)

## Мета
Тільки шафи. AI аналізує креслення, використовує затверджені правила, запитує лише критично невідоме. 3D та BAZIS — окремі наступні етапи.

## Джерела знань (за пріоритетом)
1. Явно підтверджене технологом рішення для цього замовлення.
2. Однозначні дані креслення.
3. Затверджені активні правила фабрики.
4. Схожі перевірені приклади — лише підказки, не автоматична заміна правил.

За суперечності не вигадувати рішення: показати конкретну суперечність і запитати одне виробниче рішення.

## Картка навчального прикладу
- id, дата, точна назва замовлення
- фото/креслення (джерело)
- визначені параметри та їх джерело (креслення / правило / технолог)
- початковий аналіз AI
- помилки та пояснення виправлень
- підтверджений технологом правильний аналіз
- статус: draft | approved | rejected
- версія правил, за якими перевірено

## Процес
1. AI створює аналіз і список невизначеностей.
2. Система прибирає питання, відповіді на які вже є в кресленні, правилах або підтвердженнях.
3. Технолог виправляє лише фактичні помилки та підтверджує правильний результат.
4. Після затвердження приклад стає доступним для пошуку схожих конструкцій.
5. AI-наставник може запропонувати нове правило, але не має права автоматично змінювати активні виробничі правила.

## Критерії якості
- 0 повторних питань за вже підтвердженим параметром
- 0 внутрішніх кодів у відповідях користувачеві
- 0 автоматично вигаданих критичних розмірів
- пояснення джерела кожного важливого рішення
- виробничі правила змінюються лише після підтвердження технолога

## Межі v0.1
Це специфікація навчального процесу, НЕ готова база прикладів чи автоматичне перенавчання моделі. До підключення збереження прикладів, перевірки та вибірки не заявляти, що Elvin навчається автоматично.
